## 📖 Overview
<a id="overview"></a>

**Foxtana Pro** is an innovative Firefox extension designed to enhance your web browsing experience by integrating Cortana's powerful search capabilities directly into your preferred browser. This extension allows you to redirect all Cortana searches from Microsoft's Edge browser to Firefox, ensuring that you can use your favorite search engines like Google, DuckDuckGo, or Baidu with ease. 

With the **latest version** of Foxtana Pro, you can enjoy **full functionality** that adapts to your browsing preferences. Simply install the extension, activate it, and start experiencing a seamless search experience tailored to your needs.
